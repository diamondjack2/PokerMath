# Poker Math 🂮
This is a project for me and other to use to better understand the mathematics in the game of poker and apply it to our game.


### Roadmap:
1. Cards, Combinations, & Removal ✅
2. Adding Rules of the game (which hand wins)
3. Pot Odds, Ranges, Equity 
4. Bankroll Mgmt 
5. Hand History Parsing 
6. A Toy Solver 
7. Front End (AI assisted)
