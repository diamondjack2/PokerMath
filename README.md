Poker Math is a tool I'm building to help myself and others get better at applying the math math behind poker while playing.

Currently:

Phase 1.
Building cards and poker hand combinations. Taking a two hand combo dealt ie: (7s,Ah) [7 of spades, Ace of hearts] into a standard classifcation 'A7o'.
This math turns 1326 hand combinations into 169 different classes, which serve the basis for further poker mathematics. 

Also added a check_cards.py that checks whether the cards.py generating the combinations works using whiteboarded math checks.

Roadmap:
1. Cards and Combinations 
2. Adding Rules of the game (which hand wins)
3. Pot Odds, Ranges, Equity 
4. Bankroll Mgmt 
5. Hand History Parsing 
6. A Toy Solver
